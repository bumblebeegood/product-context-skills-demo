# View Speaker Profile

## Context
Attendee looking up who a speaker is.

## Role
Attendee

## Prerequisites
- The speaker exists.

## Steps
1. Attendee selects a speaker.
2. System returns name, title, company, bio, photo URL, and website.
3. System also returns the speaker's talks ordered by start time (BR-PRG-05).
4. Attendee opens one of the talks (see `view-talk-details.md`).

## Expected Result
The attendee sees the speaker's profile and everything else they present.
