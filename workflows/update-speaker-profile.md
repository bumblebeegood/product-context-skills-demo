# Update Speaker Profile

## Context
Organizer maintaining a presenter's profile.

## Role
Conference Organizer

## Prerequisites
- The organizer is authenticated (BR-ACC-02).
- The speaker exists.

## Steps
1. Organizer selects a speaker and changes one or more profile fields.
2. System validates the new values against the Speaker data example.
3. System saves the change and sets Last updated on each of the speaker's talks (BR-SYN-02); all reads show it immediately (BR-SYN-03).

## Expected Result
The speaker's profile is current wherever the programme is shown.
