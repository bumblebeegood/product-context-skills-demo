# List Tracks

## Context
Attendee seeing the conference's themes.

## Role
Attendee

## Prerequisites
- None.

## Steps
1. Attendee requests the list of tracks without signing in (BR-ACC-01).
2. System returns each track's name, description, and display order, ordered by display order (BR-TRK-02).
3. Attendee picks a track to browse its talks (see `browse-talks-by-track-or-date.md`).

## Expected Result
An ordered list of all tracks.
