# Browse Talks by Track or Date

## Context
Attendee browsing the programme.

## Role
Attendee

## Prerequisites
- The programme contains talks.

## Steps
1. Attendee opens the programme and chooses a track, a date, or both. The system accepts the request without sign-in (BR-ACC-01).
2. System returns the matching talks ordered by start time, each with title, format, status, room, start and end time (BR-PRG-01, BR-PRG-04).
3. Cancelled talks appear marked Cancelled (BR-PRG-02).
4. Attendee scrolls through the list and picks a talk to open (see `view-talk-details.md`).

## Expected Result
A time-ordered list of talks for the chosen track and/or date.
