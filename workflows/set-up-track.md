# Set Up Track

## Context
Organizer defining the conference's themes.

## Role
Conference Organizer

## Prerequisites
- The organizer is authenticated (BR-ACC-02).

## Steps
1. Organizer provides name, description, and display order for a new track.
2. System validates the fields against the Track data example and the name against BR-TRK-01.
3. System saves the track; it appears in track lists at its display order immediately (BR-TRK-02, BR-SYN-03).
4. To change a track later, organizer submits new values; the system revalidates, saves, and updates Last updated on the track's talks (BR-SYN-02).

## Expected Result
A track exists, or is updated, and is visible in the programme.
