# Find Speaker by Name

## Context
Attendee or speaker searching for a person.

## Role
Attendee

## Prerequisites
- None.

## Steps
1. User enters part of a name.
2. System returns every speaker whose name contains the text, ignoring case, ordered alphabetically (BR-SPK-02, BR-SPK-03).
3. If nothing matches, the system returns an empty list.
4. User opens a speaker (see `view-speaker-profile.md`).

## Expected Result
A list of matching speakers.
