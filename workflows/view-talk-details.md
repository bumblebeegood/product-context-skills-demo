# View Talk Details

## Context
Attendee reading about a session.

## Role
Attendee

## Prerequisites
- The talk exists.

## Steps
1. Attendee selects a talk from a list.
2. System returns the talk's description, format, status, date, start and end time, room, track name, and speaker names without a second lookup (BR-PRG-03).
3. Times are shown in UTC (BR-TIM-01); the Date is the venue-local date (BR-TIM-02).
4. If the talk is Cancelled, its status says so (BR-PRG-02).

## Expected Result
The attendee knows what the talk covers, when and where it happens, who presents it, and whether it is still on.
