# Delete Talk

## Context
Organizer removing a talk that was created by mistake.

## Role
Conference Organizer

## Prerequisites
- The organizer is authenticated (BR-ACC-02).
- The talk exists.

## Steps
1. Organizer deletes the talk.
2. System removes the talk entirely, whether Scheduled or Cancelled (BR-TLK-09).
3. The talk no longer appears in any list; it is not reported as a change (BR-SYN-05).

## Expected Result
The talk no longer exists.
