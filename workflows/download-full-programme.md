# Download Full Programme

## Context
Integration Partner (an app, no human involved) copying the programme.

## Role
Integration Partner

## Prerequisites
- None; no authentication is needed (BR-ACC-01).

## Steps
1. Partner requests all tracks, all speakers, and all talks.
2. System returns tracks by display order (BR-TRK-02), speakers alphabetically (BR-SPK-02), and talks by start time including Cancelled ones (BR-PRG-01, BR-PRG-02), each talk with Last updated.
3. Partner stores the data and the time of the download for the next sync.

## Expected Result
A complete, current copy of the programme.
