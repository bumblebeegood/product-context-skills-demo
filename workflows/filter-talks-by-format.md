# Filter Talks by Format

## Context
Attendee narrowing the programme to one kind of session.

## Role
Attendee

## Prerequisites
- The programme contains talks.

## Steps
1. Attendee chooses a format: Keynote, Talk, Workshop, or Panel.
2. System returns only talks of that format, ordered by start time (BR-PRG-01, BR-PRG-04).
3. Attendee may add a track or date filter; the system returns talks matching all filters (BR-PRG-04).
4. If the format value is not one of the four, the system rejects the request with the Format error message.

## Expected Result
A list containing only talks of the chosen format.
